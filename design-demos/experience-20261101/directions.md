# 六个候选

## A 清流 / 最佳设计师思路：Naoto Fukasawa
借用：不费力的操作、低噪声的轮廓、主次依交互频率分配。主体为一段可读的回答。骨架：薄会话侧栏 + 居中对话流 + 按需来源抽屉。胆量只放在大面积安静的正文留白。form 来自用户要连续提问，不想管理研究设施。冷白、青绿点缀，保留产品原强调色的来源。

## B 夜航 / 最佳设计师思路：Dieter Rams
借用：强对齐、稳定工具位置、功能分组清楚。主体为问题与读写关系图。骨架：顶栏导航 + 大幅深色会话画布 + 右侧窄来源；不用永久宽左栏。胆量为深色阅读空间与淡青图形，避免终端隐喻。form 来自夜间持续学习。

## C 对照 / 现实参照：Readwise Reader
参照：https://readwise.io/read，参考板 refs/board.jpg。借用：长文阅读列、窄控制栏、来源在旁边。主体是回答与原文的对应关系。骨架：紧凑侧轨 + 左答案右来源的双页阅读。胆量为来源展开后与答案等权，而不是细小脚注。form 来自研究需要判断来源是否支持结论。

## D 精简 / 现实参照：Linear
参照：https://linear.app/features，参考板 refs/board.jpg。借用：低对比边框、分组侧栏、紧凑工具栏。主体是可扫描的对话列表。骨架：双栏队列与当前对话。胆量在高密度，不堆叠大卡片。form 来自切换多个研究主题；不选为主方向，因为容易重新成为任务管理台。

## E 直达 / 秒数轮盘 web 17
S=36，36 % 20 + 1=17：functional-brutalism。已查看技能样张。借用：清楚的链接、直线分隔、零装饰。主体为列表与直接答案。骨架：横向工具条 + 宽正文 + 下方来源。胆量为蓝色超链接和极简边线。form 来自想最快获得可检查答案。不选为主方向：对聊天阅读的情感支持较弱。

## F 书页 / 秒数轮盘 east 1
S=36，36 % 12 + 1=1：吕敬人书籍设计。已查看技能样张。借用：正文与边注分层、行距与纸色，避开巨字和实物装帧。主体为长文与边注。骨架：阅读页 + 边注 + 下方追问。胆量为书写质感与宋体正文。form 来自深读。备选保留；主方向 C 会吸收边注关系，但使用屏幕友好字体。

三版优先 A / B / C：分别服务日常聊天、专注夜间阅读、核验来源。选择须等待真实缩略图检查；不是用户批准。
