# Study Agent 体验方向探索

打开 `index.html` 可比较和进入三个可点击原型。HTML 自带样式、脚本与矢量图；不需要后端、API key 或构建。

- A 清流：居中对话流、窄会话导航、按需来源。适合日常持续聊天。
- B 夜航：深色横向空间、顶栏、图解与窄来源。适合专注阅读。
- C 对照：答案与来源并列，点击引用可定位对应段落；手机使用回答/来源切换。
- `thumbs.html` / `thumbs.png` 保留另外三个备选 D 精简、E 直达、F 书页。

建议：以 A 的日常对话为基础，吸收 C 的来源阅读。此建议不是用户选择。
三方向门仍待用户选择，因此没有 `direction-approved.md`，未改生产 UI。

## 从命令行复验

在当前目录运行 `py -3.12 verify_all.py`。要求本机已有 Python Playwright 及 Chromium；脚本自动开启临时 localhost 服务并关闭，不连接产品后端，不调用模型，不读取 `.env`。

每方向各运行 1440×900 与 375×812，覆盖输入空白、中文 IME、发送本地预置回复、附件仅本地显示、新对话与恢复、来源显示、布局溢出、浏览器异常。脚本生成方向 JSON 回执与截图，失败退出非零。C 额外检查输入转义与可点按钮尺寸；B 检查移动来源的焦点归还；A 检查真实字号变更。
