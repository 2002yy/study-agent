# A3 独立标注集 v1（冻结，盲标）

> 30 条真实 claim + 已核验片段；**不含**模型 verdict、A3 决策、原句规则结果。
> 费用 0，未调用模型。

## 1. 标注方法

对每条记录只看 `claim` 与 `passage`，在 `annotation_S_C_I_U` 列填写四选一：

| 标注 | 含义 |
| --- | --- |
| S | 证据足以支持完整事实 |
| C | 证据明确与事实矛盾 |
| I | 证据不足以确认，也无法直接反驳 |
| U | 事实或证据存在歧义，需要复核（不参与正式评分） |

**不要把“不支持”写成“反对”（C）**：两者是不同的语义关系。

盲标要求：

1. 标注者看不到模型判断、A3 是否放行、原句规则结果，也看不到分层标签；
2. 不要参考其他标注者的结果；
3. 记录标注者身份；判断有分歧时在 `disputed` 列写 `Y` 并在 `reason` 说明。

## 2. 抽样规则（可复现）

- 来源：`docs/research_quality/answer_ab` 的 20 轮归档答案；
- 只取 A2 能定位到已核验片段的 claim（A2 漏检不计入本表，另记）；
- 分层启发式（仅用于抽样，不展示给标注者）：numbers_dates, causality, polarity_relation, conflict_or_negated_passage, table_or_cross_sentence, paraphrase；
- 随机种子：`20261101`；每层最多 5 条，不足则记录缺口，不虚构；
- 冻结指纹（盲标 JSON 的 SHA-256）：`d8a706d5dec3817a19aacf1d08b68c355fd26910094338043f981e71327407ab`。

## 3. 本批规模

- 实际条数：**30**；
- 实际构成：因果关系 4，冲突与否定证据 5，数字与时间 7，同义改写 7，否定及主客体关系 5，表格与跨句推理 2
- 分层缺口（真实语料不足，未虚构）：{"causality": 1, "table_or_cross_sentence": 3}
- 同批记录的 A2 漏检（未定位到片段，不进入本表）：**60** 条；
- 片段与 claim 重叠充分的：19 / 30
  （重叠薄的条目仍保留：它们正是「候选是否够用」的检验对象）。

## 4. 冻结与评分

- 本表在完成独立标注前**不得**因模型表现而调整样本；
- 评分所需的原句规则结果、分层、A2 候选数保存在 `ANNOTATION_KEYS_V1.json`，标注者不得查看；
- 30 条只是第一轮诊断集，不是生产安全性的最终验收集。
