# A4 影子报告（零费用，离线）

> 只测量资格闸门，不发布、不调用模型；verdict 是输入数据。

## 1. 闸门指标

| 指标 | 值 |
| --- | ---: |
| 原句规则拒绝 | 5 |
| 影子路径可发布 | 5 |
| **正确增量**（拒绝→可发布→独立标注为正确） | **1** |
| **错误放行**（可发布但标注为不支持） | **3** |
| 无独立标注的放行 | 0 |
| 已测量 | 是 |
| **安全**（无错误放行且无未标注放行） | **否** |

> 3 release(s) contradict the independent annotation: this is a safety failure, not a coverage trade

## 2. 逐条

| claim | 原句规则 | 影子判定 | 可发布 | 标注正确 | 增量 | 错误放行 |
| --- | --- | --- | --- | --- | --- | --- |
| vLLM 最新 release 是 v0.32.0， | 拒绝 | supports | 是 | 是 | 是 | 否 |
| 研发投入上升使利润下滑 | 拒绝 | supports | 是 | 否 | 否 | 是 |
| B 公司收购了 A 公司 | 拒绝 | supports | 是 | 否 | 否 | 是 |
| 公司收入同比增长 | 拒绝 | supports | 是 | 否 | 否 | 是 |
| 公司利润率提升 | 拒绝 | insufficient | 否 | 是 | 否 | 否 |
| Node.js 24.11.0 是 LTS 版本 | 通过 | supports | 是 | 是 | 否 | 否 |

## 3. 解读

- **增量不是成绩，只是机会**：`正确增量` 必须与 `错误放行` 一起看；
- **错误放行是硬性安全门**：只要大于 0，`safe` 即为否，覆盖率再高也不能抵消；
- **未标注即未测量**：任何影子放行缺少独立标注时，报告不给准确率，也不判安全。

## 4. 这份样本证明了什么、没证明什么

- 证明：闸门能算出两个指标，并且会把「证据只说明同时发生、claim 却断言因果」以及「主客体互换」「否定句放行」判为错误放行；
- 未证明：真实模型的 `supports` 判断准确率——verdict 在本样本中是人工给定的输入，这正是下一步需要用真实模型影子运行去测的部分。
