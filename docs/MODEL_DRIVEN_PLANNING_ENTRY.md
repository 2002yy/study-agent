# B 模型规划进入现有执行治理（B1）

用户冻结方向：B 负责细粒度自然语言拆题，程序保留既有 episode、身份、预算、来源及恢复治理。生产不再并行调用 A 的粗粒度规划器；不增加主题分类或白名单。当前仅实施入口切片，不宣称通用 Standard/Deep 资格已经接通。

## 接口与所有权

`ResearchSemanticSession.plan` 一次调用现有 Flash，按用户最新授权为 20 秒 / 2800 tokens / SDK 零重试。模型返回 `tasks: [{question, query?}]`；可选意图与原有偏好，不提供数据库 ID。程序按 owner task ID 与问题原文生成稳定 RQ ID，保存用户完整原始问题及条件。模型原始响应（含 JSON 失败）、拒绝原因、原始提案索引与规范 ID 映射保留在既有语义事件中。

逐字相同的问题确定性去重；不同时间、实体、条件或措辞保留，不用相似度合并。继续研究时保留原有任务编号与问题原文，新任务有独立 owner。非法字段、模型伪造 ID、私有地址、无活动任务的重试不能获得合法新任务。

子问题资源上限为 24，独立于搜索额度；查询提案最多采用 5 个不同文本，同一查询可关联多个 RQ。剩余提案与无选定查询的问题在 trace 中明确暂缓，任务仍保留，不冒充已覆盖。现有执行器继续选择其预算容许的查询；Lookup / Standard / Deep 的搜索、读取及升级与发布资格不变。B 拆题实际耗时获得一次性时间补偿，最多 20 秒；Lookup 总墙钟最多 50 秒，Standard 最多 80 秒，检索自身仍为原 30/60 秒合同。收尾预留不借用，Deep child 原预算不变。原始 5 秒三题全超时的证据保留。

## 复用与边界

- `PersistentWebToolAgent` 的通用语义入口调用 B，然后复用 `recover_public_research` 和原持久任务记录。
- 已知官方资料快速路径保留；规划失败仍可进入既有显式主题/合法重试降级，但记录为 FALLBACK，不能算 B 成功。
- `ResearchSemanticSession.interpret` 与旧解析协议只为冻结 A/B 实验和兼容测试保留；生产入口不调用它，不二次聚合 B 问题。
- 读取相关性不等于 claim 支持资格；本切片不更改 claim 规划、Evidence Gate、Deep-4A 审计或 Deep-4B 发布门。
- Answer Reliability 位于独立分支提交 `0cdcfe07`，未混入本切片，原始答卷与评分不改。

## 恢复与限制

既有 episode 格式继续使用，当前读取器可恢复旧记录和最多 24 条的新记录。原始任务编号从持久化恢复，不重新分配。较旧的最多 6 条读取器无法读取大计划，回退不能只回滚旧读取器后继续读取新任务；应保留新读取兼容或退到迁移前检查点。

24 条是内存/协议资源边界，不证明 2800 tokens 总能完成所有复杂计划；超时、截断、抽取不足必须记录为实际失败。原文条件持久保存也不自动证明模型每个子问题都理解正确。过多近义问题仍可能浪费预算，本批不添加未经真实证据支持的语义合并。
