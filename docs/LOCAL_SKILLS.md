# 本地 Skill 与简单记忆

设置页的“本地 Skill”支持粘贴或上传 SKILL.md 文本、安装、启停、查看和删除。
安装后默认停用；启用后点击“下条消息使用”。最多选择三个，只对下一次单聊发送生效，
发送后清空选择；刷新也会清空临时选择。群聊不消费选择。技能正文由服务端按 ID 读取，
不把技能全文塞进用户问题或长期会话指令。

## 最小 SKILL.md

```markdown
---
name: explain-clearly
description: 用清晰步骤解释问题
---
先说明必要假设，再给关键步骤，最后用一个小例子检查结果。
```

首版只导入这个文本文件，不安装依赖，不读取附带图片/脚本，也不运行文件中的命令。
它给现有模型提供任务指导，不增加模型调用、不自动联网、不赋予额外工具权限。
是否能改善真实回答仍需获授权的模型评测；离线验证只证明正确指令进入真实请求。

技能安装状态保存在宿主 `config/local_skills.json`（Git忽略），单篇≤20000字符、最多32篇；
单次选用最多3篇、合计≤24000字符。安装和状态更新原子写入，API沿用现有Token认证。
技能停用/删除后不可选用；重试和续写保持父回合选择，不能在重试时偷偷更换或新增技能。
云端上下文禁止本地资料时，选用技能会在路由/模型调用前明确拒绝，不会静默外发正文。
Policy审计记录skill_context和数量，route只保存ID/名称/源码哈希，不把正文保存为后续指令。

## 记忆

已有“长期记忆”面板可查看当前重点和长期信息，填写候选、预览，再确认保存。
保存仍遵守已有记忆写入权限与安全模式；只读时不伪装保存成功，也不会自动改权限。
本轮是否读取个人记忆，使用设置页独立的记忆范围；选择“不读个人记忆”时不读记忆文件。
本次复用现有MemoryPanel/MemoryService，不建立第二套笔记或学习状态存储。

当前本地Skill是显式选择的文本指导；GitHub安装、脚本执行、自动任务匹配和跨会话自动选用
尚未实现，也不会把未支持的附带能力说成已安装。
